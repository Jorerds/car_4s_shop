## 开发模式约定（2026-10-01 确认）

- **按模块垂直开发**：每个模块 = 后端 + 前端 + 联调的完整闭环，验收通过后进入下一模块。
- **大模块拆两步交付**：如"预约试驾"拆为 ①后端接口 ②前端页面，每步可独立验证。
- **每模块工作流**：PRD 提炼验收用例 → 先写测试 → 后端（模型→迁移→接口）→ pytest 全过 → 前端 → 联调 → 更新本文档与测试报告。
- **演示数据**：由开发侧造 3-4 款车型演示数据，门店真实数据后续替换。
