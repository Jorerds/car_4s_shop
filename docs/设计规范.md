# 设计规范：光影画廊（Light Gallery）

> 适用范围：顾客端 H5（一期完整落地）、管理端（品牌色 + 登录页/框架，细粒度打磨二期）。
> 品牌名"星辉汽车"为占位，接入真实门店 VI 后全局替换。

## 1. 设计概念

白底画廊展示车辆：以充足留白和发丝级细线营造"展厅"感，参数如工程图纸般精确排布。
全设计仅一个记忆点——**工程图纸式参数栏**，其余元素保持克制。

## 2. 色彩令牌

| 令牌            | 色值        | 用途                     |
| ------------- | --------- | ---------------------- |
| `sea`         | `#17324F` | 品牌深海蓝：主按钮、价格、激活态、链接   |
| `sea-deep`    | `#0F2438` | 深色底：管理端侧栏            |
| `sea-soft`    | `#EEF2F6` | 品牌浅底（选中背景等）          |
| `ink`         | `#1A2330` | 主文字                    |
| `ink-secondary` | `#5A6572` | 次级文字（车型副标题）          |
| `ink-faint`   | `#98A1AC` | 弱化文字（标签、占位）          |
| `hairline`    | `#E5E7EB` | 发丝分割线：区块边界、表单下划线      |
| `mist`        | `#F5F7F9` | 浅灰区块底：图片占位、管理端底衬     |

规则：页面背景一律纯白；`sea` 只用于可点击元素与关键数字，不做大面积装饰填充。

## 3. 字体与字号

字体栈（中文优先）：`-apple-system / PingFang SC / HarmonyOS Sans SC / MiSans / Microsoft YaHei`

| 场景      | 字号    | 字重    | 说明               |
| ------- | ----- | ----- | ---------------- |
| 车名/页面标题 | 19px  | 600   | 首页主推车型名、登录标题     |
| 区块标题    | 15px  | 600   | "在售车型"、顶栏          |
| 正文/按钮   | 13–15px | 400/500 |                  |
| 价格数字    | 20px  | 600   | 必须加 `.num`（等宽数字） |
| 技术标签    | 11px  | 400   | 加 `letter-spacing: 0.15em`（`.label-tech`） |

## 4. 组件约定

- **按钮**：主按钮 `bg-sea` 白字实底；次按钮 `border-sea` 描边，同尺寸成对出现（查看详情 / 预约试驾）
- **表单**：下划线式（`border-b border-hairline`），不用描边输入框
- **参数栏**：`grid + divide-x + border` 三栏发丝线分格，标签在上、数值在下
- **标签栏**（H5 底部）：纯文字 + 激活项顶部 2px 指示线，不用图标
- **卡片**：禁止阴影与圆角堆砌；区块分隔只用发丝线或留白

## 5. 管理端映射

- Element Plus 主色覆盖为 `sea`（`admin/styles/main.css` 的 CSS 变量）
- 侧栏 `sea-deep` 底 + 浅蓝灰文字，激活项白字
- 登录页：浅灰底衬 + 白卡发丝边框
